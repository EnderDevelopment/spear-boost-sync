# SpearBoostSync

SpearBoostSync is a Fabric client-side mod for Minecraft 1.21+ that automates a keybind action for combat/movement. It triggers the use of the currently held item (Spear Launch/Boost mechanic), scans the hotbar for a Mace, and switches to it while syncing the inventory change with the server.

## Install

1. Install Fabric Loader for Minecraft 1.21
2. Place the mod jar in your mods folder
3. Launch Minecraft with the Fabric profile

## Use

- Press the configured key (default: X) to trigger the action
- The mod will automatically switch to a Mace in your hotbar if found
